# My Project

A multi-page front-end project built with HTML, CSS and JavaScript.

## Pages
- `index.html` — صفحه اصلی
- `shop.html` — فروشگاه
- `tasviehesab.html` — تسویه حساب
- `loading.html` — صفحه بارگذاری

## Structure
- `css/` — فایل‌های استایل
- `js/` — فایل‌های جاوااسکریپت
- `images/` — تصاویر، آیکون‌ها، لوگوها و پوسترها
- `fonts/` — فونت‌ها

##Info
- `Image` — گرفته شده از دیجی کالا
